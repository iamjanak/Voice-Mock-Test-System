# Voice Mock Test System

A React/Vite frontend and Django backend scaffold for a voice-based mock-test
platform. The source tree is organized for student and administrator flows,
test management, attempt evaluation, notifications, and workflow automation.

## Project structure

- `frontend/` — React application, reusable UI, pages, API services, and styles
- `backend/` — Django project and domain apps
- `automation/` — n8n workflow export scaffolds
- `storage/` — upload and object-storage notes
- `design/` — design system, screens, and diagrams
- `docs/` — product and technical documentation

## Getting started

See [docs/setup-guide.md](docs/setup-guide.md) for local setup instructions.

The page, service, and backend modules are scaffolds; application features and
API endpoints still need to be implemented.
